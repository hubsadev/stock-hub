- [ ] Decider ce qui devient mouvement.
- [ ] Decider ce qui reste hors perimetre.

- [ ] Projets / chantiers.
- [ ] Equipements suivis individuellement.

Lot 2 - Entrees et sorties stock
- [ ] Enregistrer une entree stock.
- [ ] Enregistrer une sortie stock.
- [ ] Bloquer une sortie si stock insuffisant.
- [ ] Calculer stock actuel = stock initial + entrees - sorties.
- [ ] Historiser chaque mouvement.
- [ ] Associer une sortie a un employe, chantier ou projet.



Lot 3 - Retours, equipements et affectations
- [ ] Enregistrer un retour materiel simple.
- [ ] Renseigner l'etat au retour : bon, abime, perdu, a reparer.
- [ ] Reintegrer le stock si le retour est reutilisable.
- [ ] Garder le lien avec la sortie d'origine.
- [ ] Creer un equipement avec code inventaire.
- [ ] Renseigner marque, numero de serie, etat, localisation.
- [ ] Affecter un equipement a une personne ou un projet.
- [ ] Marquer un equipement perdu, vole, defectueux ou en maintenance.
- [ ] Rechercher un equipement par code.
