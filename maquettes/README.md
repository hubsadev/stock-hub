# Contrat des maquettes HTML

Ce dossier est la cible des taches UX/UI de `exec/`.

## Structure attendue

- un dossier par module : `maquettes/<module-slug>/`
- un index par module : `maquettes/<module-slug>/index.html`
- un fichier `.html` par ecran : `maquettes/<module-slug>/ecr-xx-yy-<slug-ecran>.html`

## Regle de production

- les maquettes sont produites module par module a partir des prompts `exec/*.md`
- chaque module doit rester autonome et ne pas ecraser les autres
- les maquettes doivent rester previewables localement
- la coherence visuelle et de navigation doit etre maintenue d'un module a l'autre
- 20-stock-hub-mvp : maquette MVP Stock Hub, base simple inspiree des maquettes cible.
